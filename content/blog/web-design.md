# UI设计与前端资源

让网站变得好看，离不开设计资源的加持。这里收录了提升颜值和开发效率的必备神器。

## 🎨 设计与 UI 资源

- [Tailwind CSS](https://tailwindcss.com) - 原子化 CSS 框架，极大地提升了写样式的效率，本站的排版全靠它。
- [Iconify](https://icon-sets.iconify.design) - 超过 20 万个开源图标库集合，只要一个 `<Icon>` 组件就能随时调用。
- [DaisyUI](https://daisyui.com) - 基于 Tailwind 的组件库，提供现成的按钮、卡片、导航栏，复制粘贴就能用。
- [Google Fonts](https://fonts.google.com) - 免费的高质量英文字体库。

---

> 💡 **小建议**：如果不擅长调色，可以在 Tailwind 的色板里直接挑颜色，往往比自己去调色值更好看。

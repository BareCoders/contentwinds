# 建站框架与极速托管

买好了心仪的域名，接下来就是赋予它灵魂。这里收录了现代建站框架与免费极速托管服务，主打“免费、极速、高颜值”。

## 🚀 极速部署与托管（免费首选）

- [Cloudflare Pages](https://pages.cloudflare.com) - 本站的托管服务商。前端极速部署，自带全球 CDN，免费额度极慷慨，完美配合 GitHub 自动构建。
- [Vercel](https://vercel.com) - 前端界的宠儿。部署极快，体验极佳，通常用于托管 Next.js 或 Nuxt 等现代前端框架。
- [Netlify](https://www.netlify.com) - 老牌静态网站托管平台，功能全面，表单处理和服务端函数等功能很强。
- [GitHub Pages](https://pages.github.com) - 最基础、最经典的免费托管，可以直接把代码仓库变成网站。

## 🛠️ 现代建站框架（前端）

- [Nuxt](https://nuxt.com) - 本站使用的前端框架。基于 Vue 的全栈框架，SEO 极其友好，非常适合做内容型网站。
- [Next.js](https://nextjs.org) - 基于 React 的全栈框架，Vercel 的亲儿子，生态极其庞大。
- [Astro](https://astro.build) - 专为内容网站设计的框架。核心优势是“零 JS 默认加载”，网页打开速度快到离谱。
- [Hugo](https://gohugo.io) - 基于 Go 语言的静态网站生成器。构建速度极快，几万篇文章一秒生成。

# 内容管理与后端服务

不需要复杂的服务器配置，这里收录了适合个人开发者的轻量级内容管理与后端云服务。

## 📝 内容管理与 CMS（后端）

- [Nuxt Content](https://content.nuxt.com) - 本站的内容引擎。直接写 Markdown 就能变成精美网页，不需要搞数据库。
- [WordPress](https://wordpress.org) - 全球建站市场的绝对霸主。插件和主题多如牛毛，适合不想写代码的人。
- [Strapi](https://strapi.io) - 开源的无头 CMS（Headless CMS），可以帮你快速搭建自定义的后台 API。
- [Supabase](https://supabase.com) - 开源的 Firebase 替代品。提供了现成的数据库、登录鉴权、存储等服务，非常适合个人项目。

---

> 💡 **小贴士**：如果是写博客或导航站，首选 Nuxt Content 或 WordPress；如果是做 Web App 需要用户登录，首选 Supabase。
